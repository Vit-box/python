# KODA.md — Контекст проекта

## Обзор проекта

Это учебный Python-проект, предназначенный для изучения основ программирования и веб-разработки на фреймворке **FastAPI**.

Проект содержит:
- **Основной файл FastAPI-приложения** (`main.py`) — примеры создания API-эндпоинтов.
- **Временный тестовый файл** (`tempCodeRunnerFile.py`) — фрагменты кода для проверки отдельных конструкций Python.
- **Шпаргалку по основам Python** (`Шпора_экзамен.txt`) — конспект с базовыми операторами, задачами на работу с числами и координатами.

## Структура проекта

```
.
├── main.py                    # FastAPI приложение (учебные эндпоинты)
├── tempCodeRunnerFile.py      # Временный тестовый файл
├── Шпора_экзамен.txt          # Шпаргалка по основам Python
└── venv/                      # Виртуальное окружение Python
    └── Lib/site-packages/     # Установленные пакеты
```

## Технологии и зависимости

| Пакет | Версия | Назначение |
|---|---|---|
| **FastAPI** | 0.142.2 | Веб-фреймворк для создания API |
| **Uvicorn** | 0.54.0 | ASGI-сервер для запуска FastAPI |
| **Starlette** | 1.7.0 | Базовый ASGI-фреймворк (зависимость FastAPI) |
| **Pydantic** | 2.13.5 | Валидация данных (зависимость FastAPI) |
| **anyio** | 4.15.1 | Асинхронная абстракция (зависимость Starlette) |
| **click** | 8.5.0 | CLI-фреймворк (зависимость Uvicorn) |
| **h11** | 0.16.0 | HTTP/1.1 реализация (зависимость Uvicorn) |

## Сборка и запуск

### Активация виртуального окружения
```powershell
.\venv\Scripts\Activate.ps1
```

### Запуск приложения
```powershell
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### Доступ к API
- Главная страница: `http://localhost:8000/`
- Эндпоинт `/ok` (статус 200): `http://localhost:8000/ok`
- Эндпоинт `/not-found` (статус 404): `http://localhost:8000/not-found`
- Документация Swagger UI: `http://localhost:8000/docs`

## Правила разработки

- Проект использует **виртуальное окружение** (`venv`) для изоляции зависимостей.
- Основной файл приложения — `main.py`.
- Временные тестовые файлы сохраняются с префиксом `temp` — их можно игнорировать при работе с проектом.
- Шпаргалка (`Шпора_экзамен.txt`) содержит учебные задачи и конспекты — используется для справки по основам Python.

## Примечания

- Файл `main.py` содержит несколько определений `app = FastAPI()` — при расширении проекта рекомендуется объединить эндпоинты в одном экземпляре приложения.
- Python-проекту не хватает файлов `requirements.txt` или `pyproject.toml` для фиксации зависимостей.
- Отсутствует файл `.gitignore` — виртуальное окружение (`venv/`) следует исключить из контроля версий.
